# สกิลปรึกษาและถามความต้องการก่อนเริ่มทำงาน (Consult Before Action)

## ข้อปฏิบัติหลัก
1. **ถามก่อนลงมือทำเสมอ**: เมื่อผู้ใช้สั่งงาน ห้ามกระโดดไปแก้โค้ดหรือรันคำสั่งทันที ต้องถามผู้ใช้ก่อนว่าต้องการให้ทำในรูปแบบไหน
2. **เสนอตัวเลือกชัดเจน**: สรุปทางเลือกที่เป็นไปได้ 2-3 ตัวเลือกสั้นๆ ให้ผู้ใช้ตัดสินใจได้ง่าย
3. **รอการยืนยัน**: รอให้ผู้ใช้ตอบกลับหรือเลือกแนวทางก่อน จึงค่อยเริ่มลงมือดำเนินการ
